# Sales Insights Dashboard

## Overview
Developed an interactive Sales Insights Dashboard using SQL and Power BI to analyze business performance, sales trends, profit distribution, and customer insights.

## Tools Used
- SQL
- Power BI
- DAX
- Excel

## Key Features
- KPI Cards for Sales, Profit, and Orders
- Monthly Sales Trend Analysis
- Region-wise Profit Analysis
- Category-wise Sales Distribution
- Interactive Filters and Slicers

## SQL Operations Performed
- Data Aggregation
- GROUP BY Analysis
- Sales & Profit Calculations
- Trend Analysis Queries
